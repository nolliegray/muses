# Muses

Weighted Generative Sequencer

Required: Monome Norns
Optional: Grid and Crow

Controls
K1: Play/Pause (Long Hold)
K2: Channel Select
K3: Capture/Release Loop
K3: Reset (Long Hold)

E1: Move Pages
E2: Select Parameters
E3: Edit Parameter Value

Crow
IN 1: Clock
IN 2: Reset
OUT 1: Ch 1 CV (Root)
OUT 2: Ch 1 Gate
OUT 3: Ch 2 CV (Root)
OUT 4: Ch 2 Gate

Crow Outs can be reconfigured to Ch Velocity or Ch Trigger.

NB Voices
Output can be set to installed NB Voices in Params

Muses is named for the original three Boeotian Muses:
Aiode - Muse of Song
Melete - Muse of Practice
Mneme - Muse of Memory

These relate to the core functions of Muses to generate two channels of user-weighted notes, scales, and rhythms in which to create a practice tool to find interesting and inspiring melodies or phrases. Muses can also lock a loop for each channel to serve as a memory for a portion of the generated sequence.
